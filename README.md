# Alyalina Telegram Catalog Bot with 15% Markup

بوت تليجرام ذكي ومؤتمت بالكامل يقوم بجلب المنتجات، الصور، والأسعار الحية مباشرة من موقع شركة **Alyalina** الرسمي، مع إضافة هامش ربح تلقائي للمسوق بنسبة **15%** دون أي تدخل يدوي.

## الميزات:
- كشط وتحديث البيانات والأسعار حياً وتلقائياً من الموقع الرئيسي.
- إضافة ربح 15% وتقريب الكسور والفواصل الرياضية تلقائياً.
- عرض منسق وجذاب للصور والأسعار عبر أزرار تفاعلية داخل تطبيق التليجرام.

## طريقة التشغيل:
1. قم بتثبيت الاعتماديات: `npm install`
2. ضع توكن البوت الخاص بك في ملف `bot.js`.
3. شغّل البوت: `npm start`
