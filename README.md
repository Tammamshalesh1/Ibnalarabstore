# Ibnalarabstore

متجر إلكتروني عربي بسيط ومتجاوب.

- `index.html`: واجهة المتجر، البحث، الأقسام، السلة وإرسال الطلب.
- `admin.html`: لوحة إدارة محلية لإضافة وحذف المنتجات ومشاهدة الطلبات.

> هذه النسخة تستخدم LocalStorage للبيانات، وهي مناسبة كبداية وتجربة واجهة. لا تضع كلمات مرور أو مفاتيح سرية داخل ملفات الموقع.
